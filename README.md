## What this is

This project was created from the
[Claude Workflow Framework](https://github.com/AarvinGeorge/Claude-workflow-framework).
The framework's docs and bundles live in [`.framework/`](.framework/).

## How to start

```bash
claude
```

That's it. Claude reads `CLAUDE.md`, sees the project is fresh, and
starts Phase 1 (Discover) with you. The bundle (if applicable) gets
recommended and installed during the conversation, not up front.

No placeholders to fill in. No restructure. No `mv` commands. Discovery
happens in conversation, then `CLAUDE.md` updates itself.
